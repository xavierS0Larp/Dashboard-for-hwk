# AgriHuaiRat | ระบบทะเบียนเกษตรกร อ.ห้วยราช จ.บุรีรัมย์

ระบบ Dashboard วิเคราะห์สถิติและภูมิสารสนเทศแปลงเพาะปลูก (GIS) ปี 2565 – 2567  
ออกแบบตามสไตล์ **Modern Fintech / SaaS Minimalist** (ถอดแบบความพรีเมียม สบายตา และมีเอกลักษณ์ตามภาพต้นแบบ)  
คุมโทนสีเด่นชัด **ไม่เกิน 5 สี (Strictly 5 Colors Palette)**

---

### 🎨 ระบบ 5 สีที่ใช้ (Strict 5-Color System)
1. `#0C7C59` (Deep Emerald Green) — บัตรฮีโร่ดิจิทัล (Green Card), แท่งกราฟสูงสุด (Peak Capsule Bar), ปุ่มหลัก
2. `#A7F3D0` (Mint / Soft Sage) — แท่งกราฟลายเฉียง (Striped Bars), ป้ายอัตราเติบโต (+17.8%), กราฟเส้นความชัน
3. `#F3F4F6` (Soft Pale Gray) — พื้นหลัง Canvas และพื้นผิวปุ่ม/การ์ดย่อย
4. `#FFFFFF` (Pure White) — การ์ดคอนเทนต์, กรอบคอนเทนเนอร์ใหญ่, ตัวอักษรบนการ์ดเขียว
5. `#1E293B` (Deep Charcoal Slate) — ตัวหนังสือหลัก หัวข้อ และไอคอน

---

### 🌟 องค์ประกอบสำคัญที่ถอดแบบมาจากภาพอ้างอิง
* **บัตรเกษตรกรดิจิทัล (Digital Agri-Card)**: บัตรสีเขียวมรกตโค้งมนหรูหรา แสดงเนื้อที่เพาะปลูกรวม `94,624.1 ไร่` พร้อมไอคอนคลื่นวิทยุและตัวเลขเกษตรกร
* **กราฟแท่งทรงแคปซูล (Capsule Bars with Diagonal Stripes)**: แสดงสัดส่วนเนื้อที่พืชเศรษฐกิจ แท่งข้าวเจ้าจะเด่นด้วยสีเขียวเข้มพร้อมป้ายลอย `+42.4%` ส่วนพืชอื่นจะมีลวดลายเฉียง (Striped Pattern) ตามภาพต้นแบบ
* **กราฟเส้นแนวโน้มแบบนุ่มนวล (Smooth Spline Area Curve)**: แสดงอัตราการเติบโตของแปลงเพาะปลูกย้อนหลัง 3 ปี พร้อมปุ่มเลือกช่องทาง ทบก. vs FARMBOOK
* **แถบไอคอนด้านซ้าย (Slim Floating Sidebar)**: แถบเมนูด้านซ้ายทรงแคปซูลพร้อมปุ่มไอคอนทรงกลม
* **แผนที่แปลงเพาะปลูก GIS และตารางเกษตรกร (Directory Table)**: แผนที่พิกัดจริง อ.ห้วยราช พร้อมตารางสไตล์มินิมอลและป้ายสถานะ `● ผ่านการประชาคม`
